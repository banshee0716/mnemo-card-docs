## 使用者得到什麼

網站新增「學習科學」分區：一篇導讀加六篇入門文章（檢索練習、間隔練習、生成學習、自我解釋、認知負荷理論、
KLI 框架）。沒有心理學背景、沒用過 Mnemo-Card 的讀者，讀完一篇能（1）說出這個概念在說什麼、
（2）認出一個例子、（3）避開一個常見誤解，並知道研究支持到哪裡、自己可以怎麼開始用。
每個研究說法都有可查的參考文獻；正文不逐篇介紹論文。

## 已定（brief 已有共識，G1 一併確認）

1. **定位**：學習科學入門，不是論文導讀，也不是 Mnemo-Card 的宣傳。研究是設計的理論來源，不是產品成效的驗證；
   不宣稱 Mnemo-Card 的學習效果。正文不依賴 Mnemo-Card 也能成立。
2. **篇目與順序**：照 brief §2 表格（導讀 → 檢索 → 間隔 → 生成 → 自我解釋 → 認知負荷 → KLI）；
   資料夾 `src/content/docs/learning-science/`；側欄群組「學習科學」，側欄用短術語、頁面標題用問題。
   進階主題（認知卸載、遷移、後設認知、建構性檢索專篇）本切片不做。
3. **寫作路線**：熟悉的學習情境 → 白話概念（先中文，再附英文術語）→ 兩種做法的比較例子 → 研究發現與限制 → 可以怎麼做。
   小標題用問題句；每篇必有「例子」「研究發現與限制」「可以怎麼做」三種內容，文末固定「參考文獻」與「延伸閱讀」兩節。
   確切標題規則在 spec 定。
4. **文獻**：以 brief §4 的 20 篇為池，以 2021–2025 年綜述、後設分析、理論整理為主，保留必要經典（KLI 原始文獻）。
   **每一篇的書目與研究發現都要對照原文查證**；查不到或對不上的，不寫。參考文獻只列正文真正用到的；
   延伸閱讀挑一兩篇，各附一句閱讀指引。具體數字與「某研究發現」的句子，核對紀錄要寫頁碼或章節。
5. **跨篇界線**：照 brief §5（生成學習 ≠ 生成式 AI；認知負荷 ≠ 越輕鬆越好；間隔 ≠ 固定排程最佳、擴張間隔不是普遍規則；
   不把四種卡型對應到 KLI 知識類型；概念關係是導讀用的整理，不是因果模型）。
6. **著作權與公開**：論文只轉述，不複製段落、不放 PDF、不放付費牆內容的長引文；連結用 DOI 或出版社頁，去掉追蹤參數。
7. **網站接法**：現有三篇網址不動；首頁「先讀哪一篇」之後加一個「學習科學」入口（一段說明＋導讀頁連結）；
   導讀頁列出六篇；各篇有上下篇；測試鎖住每篇的 h2 清單、側欄順序、上下篇。

## owner 裁定（G1，2026-10-14，均採 Builder 建議）

### A. 是否分批上線

| 選項 | 內容 |
| --- | --- |
| **A1（Builder 建議）** 分兩批，依側欄順序切 | 第一批：導讀＋檢索＋間隔＋生成學習；第二批：自我解釋＋認知負荷＋KLI |
| A2 依 brief 舉例切 | 第一批：導讀＋檢索＋間隔＋自我解釋；第二批：生成學習＋認知負荷＋KLI |
| A3 一次上線 | 七頁寫完、審完再一起推送 |

建議 A1 的理由：側欄第一批是連續的 1–3 篇，沒有空號；自我解釋要交代「它是生成學習的一種具體策略」，
排在生成學習之後才能直接連過去（A2 會讓第一批的自我解釋連到尚未上線的頁面）。檢索與間隔共用 Carpenter 等人（2022），
放同一批查證一次就夠。每批剛好「三篇送 owner 審一次」。
分批時，導讀頁只列已上線的篇目，第二批上線再補；每批各走一次 G4、G5、G7。

### B. 各篇標題

建議沿用 brief §2 的暫定標題（側欄短術語＋頁面問題標題），不再改。寫作中若發現標題的問題與正文重點不合，
Builder 提出修改，隨該篇文案一起送 owner 審。請回覆「沿用」或直接改。

### C. 篇幅與文獻數

| 項目 | brief 原案 | Builder 建議 |
| --- | --- | --- |
| 正文字數 | 1,000–1,600 字（參考文獻另計） | 沿用 |
| 導讀頁 | 200–300 字 | 沿用 |
| 文獻數 | 一般 4–7 篇；框架類不硬湊 | **3–7 篇，不湊數** |

理由：brief 的文獻池裡，生成學習只有 3 篇（另可共用 Fiorella）、KLI 3 篇，查證後還可能刪掉讀不到全文的。
維持「4 篇以上」會逼我們去找新文獻，增加查證成本與風險。

### D. 產品段放法

| 選項 | 內容 |
| --- | --- |
| **D1（Builder 建議）** 有對應功能的篇目才放 | 檢索、間隔、自我解釋（可能含生成學習）在文末放一小段（2–4 句，一個 h2，例如「Mnemo-Card 怎麼用這個概念？」）：說明借鑑了什麼、使用者可以怎麼做，並寫明這是設計依據、不是成效證明。認知負荷與 KLI 不放產品段。 |
| D2 每篇都放一小段 | 七頁一致，但認知負荷與 KLI 的對應容易寫成牽強的宣傳，KLI 也容易被讀成「卡型對應知識類型」。 |
| D3 不放產品段，只在延伸閱讀放一個連結 | 最乾淨，但讀者看不到產品和概念的關係。 |

不論選哪個：產品段每一句都要對照 Mnemo-Card 正式版畫面核對（例：卡片背面是一段概述加兩個提示；
排程是固定遞增與每週間隔，不能暗示是最佳排程）；與主程式範例卡講過的檢索練習、自我解釋、建構性檢索說法一致。

### E. 讀不到全文的文獻

| 選項 | 內容 |
| --- | --- |
| **E1（Builder 建議）** 先找合法公開版，找不到就降級 | 依序找出版社開放取用版、PubMed Central、作者或機構公開的作者版。都找不到：不支撐任何具體說法（數字、研究設計、「研究發現…」），可列延伸閱讀並註明「僅讀過摘要」，或從參考文獻拿掉。若讀不到的是某篇的主幹文獻（例如 Carpenter 等人 2022、Koedinger 等人 2012），停下問 owner 換來源或改寫範圍。 |
| E2 允許用摘要支撐 | 只寫摘要裡明寫的結論，標註依據是摘要。省查證成本，但摘要常省略條件與限制，容易把研究講得太滿。 |
| E3 一律換成讀得到的來源 | 最穩，但可能換掉原本挑好的文獻，要重新找、重新查證。 |

- 第三篇〈安裝並第一次產卡〉的 `next: false`：Builder 建議**不改**（第三篇是產卡步驟，下一篇接到學習科學會打斷讀者的操作流程；

## 非目標

- 現有三篇文章的內容（首頁只加入口）；Mnemo-Card 主程式與技能的任何改動；版型與樣式；附圖與概念關係圖
  （brief 提到的關係圖本切片不畫，導讀頁用文字說明篇目關係）。
- 進階主題專篇；任何學習成效數據或「Mnemo-Card 有效」的說法；論文 PDF 或長段引文。

## 品質線

- 每個研究說法都能在所引文獻的原文找到依據（核對紀錄寫頁碼或章節）；由全新工作階段的子代理核對，作者不自驗。
- 書目（作者、年份、篇名、期刊、卷期、頁碼或篇號、DOI）逐筆對照出版社頁或原文。
- 產品段的每個產品行為對照 Mnemo-Card 正式版（主程式 `STATUS.md` 記錄的 main）核對；不寫主程式未公開的細節。
- 讀者驗收三問（理解概念、辨認例子、避開誤解）由核對者回答，不能回答的段落要修。
- 既有的頁面、連結、搜尋、手機寬度、鍵盤與無障礙測試維持綠燈；`npm run check:public` 乾淨。

## 等級

LOW。新增靜態文章；不涉及認證、資料庫、資料刪除、匯入、付款或同步。風險集中在內容正確性（文獻與產品說法），
由逐篇核對處理。
