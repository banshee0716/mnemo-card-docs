這個分區是學習科學的入門文章，每篇介紹一個概念：它在說什麼、研究支持到哪裡、常見誤解，以及可以怎麼開始用。不需要心理學背景。

你不需要用過 Mnemo-Card：這些研究是它設計時參考的理論來源，不是它學習成效的證明。

## 從哪一篇開始？

依順序讀最順，每篇也能單獨閱讀：

- [〈檢索練習〉](retrieval-practice/)：為什麼試著把內容想出來，本身就是一種學習。
- [〈間隔練習〉](spaced-practice/)：為什麼同樣的練習量分散到不同時間，通常記得更久。
- [〈生成學習〉](generative-learning/)：為什麼筆記整理得完整，不一定代表理解了。
- [〈自我解釋〉](self-explanation/)：為什麼要問自己「這一步為什麼成立」。
- [〈認知負荷理論〉](cognitive-load/)：為什麼內容的呈現方式會影響好不好懂。

前兩篇常一起用：把檢索練習分散在不同時間做。自我解釋可以看成生成學習的一種做法。認知負荷理論則談教材怎麼呈現。這是為了方便閱讀的整理，不是某個理論提出的因果關係。
