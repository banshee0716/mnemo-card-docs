## 使用者得到什麼

〈第一次使用 Mnemo-Card〉從「只走完一張範例卡的第一輪」，擴充為受邀學習者完整的使用旅程：
登入 → 認識工作區 → 建牌組與卡片 → 第一次練習 → 建立排程 → 之後回來複習 → 管理內容 → 帳號與登出 → 遇到狀況怎麼辦。
讀者讀完能自己走完一整輪，也知道到期時去哪裡找、內容怎麼改。文章需要附圖；圖還沒拍，先在每個需要圖的位置放一行小字佔位。

### B. 帳號與登入的寫法（需要你確認實際的帳號安排）

### C. 圖片佔位的寫法

照你的要求，在正文中用小字佔位，讀者在網站上看得到。Builder 建議格式（MDX 的 `<small>`，加一個 class 方便之後換圖時用測試找出來）：

> <small>〔附圖 3：牌組內部，標出「新增卡片」與「開始學習」。桌機寬度，示範資料〕</small>

每張寫：編號、哪個畫面、要標出什麼、桌機或手機。預估 10–14 張。截圖之後一律用示範資料與示範帳號（AGENTS.md）。
如果你不希望佔位在正式站上被讀者看到，改用 HTML 註解（只在原始檔看得到），請告訴我。
