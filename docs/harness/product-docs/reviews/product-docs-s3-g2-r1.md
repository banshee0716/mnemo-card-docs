### F26 P1 — AC22 的禁用字串會擋到規格要求寫出的否定句

- **位置**：spec-slice3 AC22 第 2 點；ticket 06 驗收「變異」；ticket 08 第 6 點。
- **問題**：AC22 禁止全部學習科學頁出現「保證」「最佳排程」。可是規格本身要求寫出這兩個詞的否定句：

    最自然的寫法就是「沒有一套最佳排程」或「有沒有最佳排程？」這樣的 h2；

  - 「保證」「最佳排程」改為只檢查產品段 h2 底下的內容，或改用 AC10 的做法：先找出含該詞的句子，只允許 owner 同意文案中的那幾句；
