## 6. 物理例子檢查

- 情境：物體掛在兩條**垂直**繩子下、靜止。兩條拉力都向上、重力向下，沒有水平力。靜止表示加速度為零，依牛頓第一（第二）定律合力為零，所以 T₁ + T₂ = mg。文案「兩條繩子的拉力加起來等於物體的重量」正確。
- 學生 B「物體沒有在動，表示向上和向下的力互相抵消」：靜止→合力為零，方向正確（反過來，合力為零也可能是等速運動，但 B 只用了正確的那個方向）。
- 「如果物體在加速，這個等式就不成立了」：繩子垂直時所有力都在鉛直方向，若有加速度必定是鉛直方向，此時 T₁ + T₂ − mg = ma ≠ 0，等式確實不成立。正確。
- 選垂直繩子避免了分力計算，適合入門讀者；比 1989 原例題（三條繩子交會成結，p.149）簡化，但沒有說成原研究的題目。
- 結果：PASS。
