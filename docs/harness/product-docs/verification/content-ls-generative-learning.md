## 6. 例子的常識正確性

- 「高山上水不到 100°C 就會沸騰」：正確。氣壓隨高度降低，沸點跟著降低（海拔約 3,000 公尺時約 90°C）。PASS
- 筆記 B（複核修訂後）「水要沸騰，水中產生的蒸氣要撐得過外面空氣的壓力；水越熱，蒸氣越強。高山空氣稀薄、氣壓低，蒸氣不必那麼強就撐得過，所以不到 100°C 就沸騰」：符合「蒸氣壓隨溫度上升，等於外界壓力時沸騰」的原理。初核指出缺的那一環（水越熱，蒸氣越強）已補上，因果鏈完整，白話化程度適當。PASS
- 「壓力鍋正好相反：把鍋內壓力加大，水要更熱才會沸騰」：正確（壓力鍋內沸點可到約 120°C）。PASS
- 筆記 A「高山氣壓低。氣壓低，沸點低。所以高山上水的沸點較低」：正確，作為「只換位置」的對照恰當。PASS
