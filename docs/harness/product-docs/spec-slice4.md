- **R30 上下篇**：照側欄順序自動產生。第一篇 `prev: false`（不變），下一篇變成〈之後的複習與管理〉；
  新頁上一篇是第一篇、下一篇是〈認識 mnemo-study-cards〉；〈認識 mnemo-study-cards〉的上一篇變成新頁。其餘頁不變。

- **R31 首頁**：「先讀哪一篇」在第一篇的 `LinkCard` 之後加一張連到新頁的 `LinkCard`，並更新第一篇卡片的說明句；
  hero 與首頁 `description` 視需要補一句。改法隨文案送 owner，首頁其他文字不動。

- **R32 第一篇〈第一次使用 Mnemo-Card〉的範圍**：從登入寫到建立複習排程為止。h2 提案（文案定稿時可調，送 owner）：
  1. 登入並進入工作區（R9 不變）
  2. 認識工作區：側欄四項「首頁」「我的牌組」「匯入」「設定」各是什麼；首頁主卡會隨狀態改變
  3. 建立第一副牌組
  4. 新增第一張卡片：先選卡型（四型各一句，用畫面上的說明）、載入範例、編輯欄位的必填與可選；
     說明編輯器的「提取提示」就是學習時的「檢索提示」
  5. 開始第一次練習：學習畫面（進度、第幾張、上一張／下一張、翻面）與鍵盤快捷鍵
  6. 讀一張卡，再試著自己說出來（保留現有練習方法）
  7. 記錄熟悉度並完成這一輪：評分後自動前進、漏評提示、完成畫面（標題「複習完成！」、用時、熟悉度分佈）
  8. 安排下一次練習：排程選單預設「遺忘曲線」、兩種模式、按「建立複習排程」、建立後模式鎖定、去哪裡看下次日期
  9. 接下來：連到〈之後的複習與管理〉與 mnemo-study-cards 兩篇

  必修正 intent「已定 3」列的三處不符。頁內錨點連結（現有的 `#7-安排下一次練習`）改成新標題的錨點。

- **R33 新頁〈之後的複習與管理〉的範圍**：h2 提案（文案定稿時可調，送 owner）：
  1. 到期時回來複習：首頁與牌組列表的「今日待複習」「逾期 N 天」、首頁「繼續複習」、到期複習完成後推進下一階段
  2. 還沒到期也可以額外練習：完成畫面的選項與按鈕文字照畫面寫（含畫面上的英文「Practice」），不推進排程
  3. 走完一輪之後：「已精通」的意思（這一輪排程走完，不是測驗結果）、「重置排程」會清除熟悉度且無法還原、之後顯示「第 2 輪」
  4. 管理牌組與卡片：牌組設定（改名稱與說明）、編輯卡片、刪除卡片與牌組（無法還原，有確認）
  5. 匯入與匯出：匯入頁四步的名稱、連到〈安裝並第一次產卡〉看完整例子；「匯出 Markdown」
  6. 登出：側欄底部「登出」
  7. 遇到狀況時：登入已過期、離線、同一副牌組在其他視窗學習、評分尚未同步，每項一兩句，只寫畫面上的訊息與讀者該做的事
  8. 換成自己的學習內容：沿用第一篇現有的結尾段落，連到 mnemo-study-cards 兩篇

  另在適當位置明說：產品目前沒有統計或歷史頁，看得到的進度是牌組狀態、下次日期、每張卡的熟悉度與完成畫面。

- **R34 帳號（owner G1 B1）**：R9 照舊，並延伸到新頁：兩篇都不教「建立帳號」、驗證信、「忘記密碼？」、
  「變更密碼」、「登出所有裝置」。owner 說明：介面上的帳號相關功能沒有開資料庫權限。新頁若需要提到密碼，
  只能用 R9 核准的那一句「如果忘記密碼，請聯絡提供帳號給你的研究者」。

- **R35 只寫桌機與平板（owner G1）**：手機版還沒修，不寫手機窄版的操作或差異；刪掉第一篇現有的兩處手機窄版說明
  （「⋯」選單找「新增卡片」、評分簡稱）。寫到鍵盤快捷鍵時，說明這是有實體鍵盤時可用。

- **R36 圖片佔位（owner G1 C）**：
  1. 每個需要圖的位置放一行，格式固定：
     `<small class="figure-placeholder">〔附圖 N：畫面名稱；要標出的元素。桌機寬度，示範資料〕</small>`
     自成一段，前後空一行；N 每篇從 1 起連號。
  2. 內容只描述「要拍什麼」，不寫真實帳號、真實信箱、受試者或研究資料；之後的截圖一律用示範資料與示範帳號。
  3. 數量：第一篇 6–9 張、新頁 4–7 張。一個 h2 最多兩張。
  4. 佔位不計入字數。換成真圖是之後的切片，本切片不做。

- **R37 產品事實**：每個按鈕名稱、畫面文字與操作結果，都對照主程式 `STATUS.md` 記錄的正式版 main 核對。
  盤點中標為「由程式推得、未見實機畫面」的行為，寫進文章前由 S3 核對者以程式確認；確認不了就不寫。
  用詞與畫面一致（例如完成畫面標題是「複習完成！」，不要另稱「學習完成」）。

- **R38 不宣稱成效**（同 R27）：排程是安排回來的時間；熟悉度是自評，不改變間隔；「已精通」是排程走完。
  不用「保證」「最佳」「個人化」「演算法」「證實」「有效提升」。

- **R39 篇幅與寫法**：
  1. 正文中文字數（不含註解與佔位）：第一篇 2,800–3,800；新頁 2,000–3,000。
  2. 每個 h2 開頭一句說這節做什麼；步驟用編號清單，說明用段落；表格只用於比較（例如兩種排程模式）。
  3. 沿用第一篇現有的語氣與名詞（卡片、牌組、熟悉度、排程）；按鈕與畫面文字一律加「」。
  4. 不放程式碼區塊。

- **R40 既有連結**：學習科學三篇產品段連到 `../../first-use/` 的連結照舊有效；間隔練習產品段說「操作方式見〈第一次使用〉」，
  排程建立仍在第一篇，不必改。首頁 hero 按鈕不動。
